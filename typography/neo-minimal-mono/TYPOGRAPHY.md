# Neo Minimal Mono

Modern developer-craft duo (`Geist` + `Geist Mono`) engineered for high-density interfaces, CLI dashboards, and minimalist design systems.

## Font Pairing Rationale
- **Display & UI (`Geist`):** Razor-clean neo-grotesk geometry with crisp tight tracking (`-0.03em`) at heading scale.
- **Mono (`Geist Mono`):** Native companion monospace sharing exact vertical metrics for seamless inline code and telemetry badges.

## OpenType & Numeric Rules
- Use `font-variant-numeric: tabular-nums` on every counter, latency value, and table column.
- Keep uppercase micro-labels at `letter-spacing: 0.08em`.
