# Technical Superfamily

Unified engineering tri-voice system (`IBM Plex Sans` + `IBM Plex Serif` + `IBM Plex Mono`) sharing identical x-height and stem metrics across UI chrome, technical prose, and code blocks.

## Font Pairing Rationale
- **Display & UI (`IBM Plex Sans`):** Crisp neo-grotesque geometry with unambiguous glyphs (`1/I/l`).
- **Editorial Callouts (`IBM Plex Serif`):** Harmonized serif cut for pull quotes and specification headers.
- **Mono (`IBM Plex Mono`):** Native companion monospace for telemetry readouts and CLI snippets.

## OpenType & Numeric Rules
- Strict `font-variant-numeric: tabular-nums` across metrics and tables.
- Uppercase labels use `letter-spacing: 0.08em`.
