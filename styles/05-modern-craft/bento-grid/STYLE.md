# Bento Grid / Modular Product Showcase

High-craft modular product showcase aesthetic built on soft neutral aluminum-white bento tiles, generous `18px` radii, crisp typographic hierarchy, and a single precision cobalt link accent.

## Core Tokens & Surfaces
- **Canvas & Surfaces:** Cool light studio ground (`#f5f5f7`), pure white modular bento tiles (`#ffffff`), and delicate neutral hairlines (`#e0e0e0`).
- **Ink:** Deep graphite headlines (`#1d1d1f`), readable charcoal body (`#333333`), and calm caption gray (`#7a7a7a`).
- **Accent:** Precision cobalt blue (`#0071e3`, hover `#0066cc`) for primary pill CTAs and feature links.

## Typography & Layout
- Asymmetric multi-span bento grids (`12px–16px` gutters) where each tile isolates a single metric, hardware visual, or concise value prop.
- Tightly tracked geometric sans headlines (`-0.03em`) with generous internal tile padding (`28px–36px`).

## Forbidden Anti-Patterns
- No crowded multi-paragraph copy inside bento tiles or harsh thick black brutalist outlines.
- Avoid mixing competing primary hues — let photography and typography anchor each tile.
