# Motion Slate Minimal

Ultra-quiet neutral zinc documentation canvas with 1px hairline component frames and zero brand-hue distraction so interactive primitives take center stage.

## Core Tokens & Surfaces
- **Canvas:** Pure crisp white (`#ffffff`) paired with subtle zinc-50 specimen wells (`#f8f8f9`) and zinc-100 hover states (`#f4f4f5`).
- **Ink & Borders:** High-contrast zinc-900 primary ink (`#18181b`), zinc-500 metadata (`#71717a`), and delicate `1px` hairline frames (`#e4e4e7`).
- **Accent:** Achromatic obsidian (`#18181b`) primary actions with understated emerald live status (`#059669`).

## Motion Rules
- Let micro-transitions and layout morphs carry all visual drama; chrome stays completely calm and colorless.
- Use smooth spring transitions (`stiffness: 320, damping: 28`) for shared-element highlights.

## Forbidden Anti-Patterns
- Never inject loud multi-color gradients or heavy box shadows that compete with the interactive specimens inside the frame.
- Avoid thick black brutalist borders that turn quiet documentation into a poster.
