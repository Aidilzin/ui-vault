# Retro Web 96 / Directory Chrome

Unfiltered mid-90s technical catalog aesthetic built around pure white document grounds, sage-and-steel table headers, classic underlined `#0000ee` hyperlinks, and crisp `0px` cell dividers.

## Core Tokens & Surfaces
- **Canvas & Surfaces:** Stark white document ground (`#ffffff`), muted sage/steel directory bands (`#c0d4a7`, `#a5b8c0`), and hard `1px` black table rules (`#000000`).
- **Ink & Links:** Pure black copy (`#000000`), classic browser cobalt links (`#0000ee`), and visited purple (`#6a26a4`).
- **Accents:** Industrial red callout badges (`#e91d2a`) and amber spec highlights (`#fcc20f`).

## Typography & Layout
- Dense multi-column catalog tables, explicit breadcrumb trails, and crisp monospace SKU/spec codes with zero rounded corners (`0px`).

## Forbidden Anti-Patterns
- No `backdrop-filter: blur()`, modern pill buttons, soft shadows, or smooth parallax scroll hijacking.
- Keep link underlines explicit and contrast high.
