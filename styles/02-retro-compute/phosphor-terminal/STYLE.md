# Phosphor Terminal / Modern Shell Chrome

Next-generation developer shell aesthetic pairing deep obsidian-violet terminal panes with crisp phosphor-green output, acid-chartreuse prompt cursors, and ultra-fast keyboard transitions.

## Core Tokens & Surfaces
- **Canvas & Surfaces:** Deep terminal obsidian (`#1a1522`), command block panes (`#0b0c10`), and subtle `1px` dividers (`rgba(229, 247, 212, 0.14)`).
- **Ink:** Soft phosphor tint (`#e5f7d4`) and muted shell gray (`#a5a7ad`).
- **Accents:** Acid chartreuse prompt highlight (`#edf872`), terminal green nominal (`#43c251`), and electric violet command badges (`#8b5cf6`).

## Typography & Layout
- Monospace-first command blocks with explicit prompt prefixes, `2px–8px` tabbed shell chrome, and `tabular-nums` execution timers.

## Motion Rules
- Ultra-fast `100ms–150ms cubic-bezier(0.16, 1, 0.3, 1)` command focus and block selection transitions; zero slow theatrical delays.

## Forbidden Anti-Patterns
- Never sacrifice monospace legibility with excessive CRT scanline opacity or blurry glow filters on terminal output.
