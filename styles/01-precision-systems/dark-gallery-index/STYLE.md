# Dark Gallery Index / Curated Directory

Ultra-dark showcase index pairing near-black gallery backdrops with razor-sharp card frames, full-pill category filters, and sparse high-chroma tag accents.

## Core Tokens & Surfaces
- **Canvas & Surfaces:** Deep gallery obsidian (`#0b0b0b`), stepped dark cards (`#141414`), and subtle `1px` hairlines (`rgba(255, 255, 255, 0.12)`).
- **Ink:** Crisp off-white (`#f5f5f5`) and neutral cool gray metadata (`#8c8c8c`).
- **Accents:** Sparse electric tag highlights (`#00e9b2` mint, `#ffcf00` amber, `#00bfff` cyan) used exclusively on micro-pills and featured badges.

## Typography & Layout
- Tight sans display headers paired with `9999px` filter pills and crisp `8px` preview frames.

## Motion Rules
- Snappy `120ms–180ms cubic-bezier(0.2, 0, 0, 1)` hover transitions with `500ms ease` media fade-ins.

## Forbidden Anti-Patterns
- Never apply multi-color tag accents to card backgrounds; keep cards matte dark so embedded artwork pops.
