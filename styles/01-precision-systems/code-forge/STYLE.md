# Code Forge / Developer Platform Neutrals

Battle-tested code-collaboration aesthetic distilled from GitHub Primer Primitives (MIT License), pairing WCAG-verified dark/neutral canvas steps with unmistakable syntactic diff greens, reds, and slate-blue focus signals.

## Core Tokens & Surfaces
- **Canvas & Surfaces:** Deep repository canvas (`#0d1117`), elevated header/card chrome (`#161b22`), and crisp `1px` structural borders (`#30363d`).
- **Ink:** High-legibility foreground (`#e6edf3`) and muted commit/metadata slate (`#8b949e`).
- **Semantic Accents:** Merge/add emerald (`#238636` / `#3fb950`), diff/fault crimson (`#f85149`), and accessible link blue (`#2f81f7`).

## Typography & Layout
- System sans headings paired with crisp monospace diffs, branch pills, and `6px` utilitarian borders.

## Forbidden Anti-Patterns
- No glowing neon gradients or decorative shadows that obscure code diffs or status badges.
