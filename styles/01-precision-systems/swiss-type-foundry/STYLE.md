# Swiss Type Foundry / Specimen Grid

High-craft type specimen aesthetic combining crisp gallery-white surfaces, exposed `1px` index grids, oversized interactive glyph testers, and a single vermilion specimen accent.

## Core Tokens & Surfaces
- **Canvas & Surfaces:** Gallery white (`#fafafa`), cool specimen trays (`#ededed`), and crisp neutral `1px` rules (`#d4d4d4`).
- **Ink:** Pure black glyphs (`#000000`) and mid-gray weight/axis metadata (`#666666`).
- **Accent:** Vermilion specimen red (`#ff2f00`) used sparingly for try-now pill buttons and active axis highlights.

## Typography & Layout
- Extreme typographic scale contrast (`11px` mono axis metadata vs `72px+` interactive specimen headlines), `3px` specimen boxes paired with `999px` pill tags.

## Motion Rules
- Crisp `100ms–200ms cubic-bezier(0.22, 1, 0.36, 1)` interactive controls and `300ms ease-out` specimen reveals.

## Forbidden Anti-Patterns
- No blurred shadows, decorative illustrations, or competing accent colors that distract from letterform silhouettes.
